# 🪔 Kerala Housewarming Invitation — Griha Pravesham

A grand digital invitation web card for a **Griha Pravesham (Housewarming)** ceremony in Kerala, crafted for an Advocate's family.

## ✨ Features

- 🪔 **Animated Diya lamps** with flickering glow effects
- 🌸 **Floating flower petals** animation (roses, marigolds)
- ✨ **Gold particle background** — shimmering Kerala royal aesthetic
- ⏱️ **Live countdown timer** to the event date
- 📋 **Programme schedule** — Ganapathi Homam → Kerala Sadhya → Reception
- ⚖️ **Advocate designation** with Bar Council of Kerala badge
- 🌺 **Kolam motifs** and traditional Kerala cultural elements
- 📱 **Responsive design** — works on mobile and desktop
